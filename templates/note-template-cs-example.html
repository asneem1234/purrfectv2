Algorithms Basics

  • Definition: Step-by-step procedure to solve a problem
  • Key properties: Correctness, Efficiency, Finiteness
  • Time Complexity: Measure of execution time
  • Space Complexity: Memory usage
⌟

Big-O Notation

Common time complexities:

  • O(1) - Constant time
  • O(log n) - Logarithmic
  • O(n) - Linear time
  • O(n log n) - Linearithmic
  • O(n²) - Quadratic time
  • O(2ⁿ) - Exponential time
⌟

Common Data Structures

  • Arrays: Fixed-size collection
  • Linked Lists: Dynamic collection with nodes
  • Stacks: LIFO (Last In First Out)
  • Queues: FIFO (First In First Out)
  • Trees: Hierarchical structure
  • Graphs: Nodes with edges
⌟

Sorting Algorithms

  • Bubble Sort: O(n²)
  • Selection Sort: O(n²)
  • Insertion Sort: O(n²)
  • Merge Sort: O(n log n)
  • Quick Sort: O(n log n) average
  • Heap Sort: O(n log n)
